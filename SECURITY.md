# Security policy

## Reporting a vulnerability

Please report security issues **privately**, not as a public issue.

Use the **Security** tab on this repository, then "Report a vulnerability". That
opens a private channel visible only to the maintainers.

## What to expect

This is a small studio, not a vendor with an on-call rota. We aim to acknowledge
a report within a week. Fixes go out as a new release, and the advisory is
published once a fix is available.

## Scope

Only the latest release is maintained. There are no long-term support branches.

WooExports is used on live client sites, so genuine reports are taken seriously even
though the plugin carries no formal support commitment.
